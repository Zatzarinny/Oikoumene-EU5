# Oikoumenē: Dynamic Place Names for Europa Universalis V

Oikoumenē expands dynamic place names in EU5, so the same city or province can appear under different historical or culturally adapted names during a campaign. As countries spread beyond their historical borders, the naming goes with them.

**Current version:** v0.16 – “Jambūdvīpa”

## What it adds

- Dynamic location names
- Dynamic province names
- Dynamic colony names
- Almost 9,000 additional personal, dynasty, and lowborn names
- Almost 19,000 additional ship names
- 618 city flavour descriptions
- Support for English, Portuguese, French, German, Polish, Russian, Spanish, and Turkish versions of the game

## How names are chosen

Where I can, I use names that are actually attested for the period, including historical exonyms.

I do not automatically use the modern exonym just because a language happens to use it today. Many modern forms are later or standardised. If an older form is known, I use the one that makes sense for the period instead.

When there is no historical form to work with, I reconstruct or adapt one from the language itself – its historical spelling and sound system, its morphology, and the way it normally forms place names. I use the same approach when a country expands into places where its language was never historically spoken.

## Corrections and contributions

If you find a typo, a broken name, a missing form, an inconsistent spelling, or know a better historical or linguistic solution, please open an Issue.

Sources are especially useful when you have them.
